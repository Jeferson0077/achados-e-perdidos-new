# 🏷️ Sistema de Achados e Perdidos

Sistema web desenvolvido para modernizar o processo de **Achados e
Perdidos** de um clube esportivo.

O projeto nasceu da observação de um processo real que era realizado
utilizando **Google Planilhas** e **Google Sheets**. O objetivo é
automatizar o cadastro, organização, consulta e gerenciamento dos itens
encontrados, reduzindo o trabalho manual e aumentando a eficiência
operacional.

# 📋 Fluxo do Sistema

``` text
Encontrar objetos
        ↓
Tirar todas as fotos
        ↓
Selecionar todas as fotos
        ↓
Conferir/Reorganizar a ordem
        ↓
Cadastrar item por item
        ↓
Sistema gera os códigos automaticamente
        ↓
Itens disponíveis para consulta
        ↓
Retirada ou Doação
```
